## Critical Gap: runType Mismatch (MAP-03, MAP-04, MAP-05)

**File:** `pages/api/admin/data-map/periods/[id]/trace.ts` line 37

The trace API fetches the ComputeRun with `runType: 'rsp_usage'` but `ingestUsagePeriod()` creates ComputeRuns with `runType: 'actuals_ingest'`. This means the Compute Run node, MetricResults node, and Intelligence Update node are **always empty** for every RSP period.

**Fix (one line):**
```typescript
// Current (line 37):
where: { orgId: period.orgId, runType: 'rsp_usage' },
// Fix:
where: { orgId: period.orgId, runType: 'actuals_ingest' },
```
