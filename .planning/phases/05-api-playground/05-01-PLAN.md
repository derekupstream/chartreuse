Extract all pipeline logic from `pages/api/rsp/usage.ts` into a new `lib/rsp/ingestUsagePeriod.ts` file.

Define and export these types at the top of the file:

```typescript
export type EventRow = {
  reusable_type: string;
  in_warehouse_events: number;
  out_warehouse_events: number;
};

export type IngestParams = {
  orgId: string;
  clientId: string;
  dateMin: Date;
  dateMax: Date;
  events: EventRow[];
  submittedByKeyId: string;
  accountId: string | null;
  rawPayload: unknown;
};

export type IngestResult = {
  newPeriodId: string;
  overlappingCount: number;
  metrics: {
    co2AvoidedKg: number;
    waterSavedGallons: number;
    wasteDivertedLbs: number;
    totalUnits: number;
  };
};
```

Export `async function ingestUsagePeriod(params: IngestParams): Promise<IngestResult>` containing the full pipeline from usage.ts steps 4–7:
- Step 4: calcImpact per event → build productData array
- Step 5: find overlapping active periods (prisma query using orgId, clientId, dateMin/dateMax)
- Step 6: startComputeRun (runType: 'actuals_ingest')
- Step 7: prisma.$transaction to create UsageTimePeriod + products, then update superseded periods; saveMetricResults + finishComputeRun

On error: call `finishComputeRun(computeRunId, 'failed', err?.message)` then re-throw.

Return `{ newPeriodId, overlappingCount: overlapping.length, metrics: { co2AvoidedKg, waterSavedGallons, wasteDivertedLbs, totalUnits } }`.

Imports needed: `crypto`, `prisma`, `calcImpact` from `lib/rsp/impactFactors`, and the four functions from `lib/governance/computeRun`.
