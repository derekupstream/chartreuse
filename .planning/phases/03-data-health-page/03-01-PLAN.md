  <action>
    Append the following model to the END of prisma/schema.prisma (after the last model). Do NOT modify any existing models.

    ```prisma
    model DataHealthIssue {
      id                   String    @id @default(uuid()) @db.Uuid
      createdAt            DateTime  @default(now())
      updatedAt            DateTime  @updatedAt
      issueType            String
      severity             String
      entity               String
      entityId             String    @db.Uuid
      details              Json?
      status               String    @default("open")
      acknowledgedAt       DateTime?
      acknowledgedByUserId String?
      note                 String?

      @@unique([issueType, entityId])
    }
    ```

    Key constraints:
    - `entityId` MUST use `@db.Uuid` even though there is no foreign key — entity IDs are UUIDs across Project/SingleUseLineItem/ReusableLineItem tables
    - `acknowledgedByUserId` MUST be plain `String?` with NO `@db.Uuid` — it references `User.id` which is a Supabase auth UID (plain string, not a PostgreSQL UUID column)
    - `@@unique([issueType, entityId])` is the upsert key — without it, re-scan creates duplicate rows
    - `status` defaults to `'open'`; valid values are `'open'`, `'acknowledged'`, `'resolved'`
    - `severity` valid values: `'error'`, `'warning'`
  </action>
