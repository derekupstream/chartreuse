    - `'validation'` — label: "Validation", data: `{ type: 'validation', period: trace.period }`
    - `'dedup'` — label: "Dedup Check", data: `{ type: 'dedup', period: trace.period, priorPeriod: trace.priorPeriod }`
    - `'usage-period'` — label: "Usage Period", data: `{ type: 'usage-period', period: trace.period }`
    - `'products'` — label: `${trace.period.products.length} Products`, data: `{ type: 'products', products: trace.period.products }`
    - `'compute-run'` — label: "Compute Run", data: `{ type: 'compute-run', computeRun: trace.period.computeRun }` (if computeRun exists, else show "No Compute Run")
    - `'metric-results'` — label: `${trace.period.computeRun?.metricResults.length ?? 0} Metrics`, data: `{ type: 'metric-results', metricResults: trace.period.computeRun?.metricResults ?? [] }`
    - `'intelligence-update'` — label: "Intelligence Update", data: `{ type: 'intelligence-update', metadataJson: trace.period.computeRun?.metadataJson }`

    **If priorPeriod exists**, also add node:
    - `'prior-period'` — label: "Prior Period (Superseded)", style: `{ opacity: 0.5, background: '#d9d9d9' }`, data: `{ type: 'prior-period', priorPeriod: trace.priorPeriod }`

    **Node status color lookup** (function `getNodeStyle(nodeId, trace)`):
    ```
    'api-request', 'validation', 'dedup', 'intelligence-update' → grey synthetic: background '#f0f0f0', border '#d9d9d9'
    'usage-period' → based on period.status:
      active → green: background '#f6ffed', border '#52c41a'
      superseded → orange: background '#fff7e6', border '#fa8c16'
      failed → red: background '#fff2f0', border '#ff4d4f'
      needs_review → blue: background '#e6f4ff', border '#1677ff'
    'products' → inherit usage-period status color (or grey if no products)
    'compute-run' → based on computeRun.status:
      success → green
      failed → red
      running → blue: background '#e6f4ff', border '#1677ff'
      null → grey
    'metric-results' → inherit compute-run status
    'intelligence-update' → grey
    ```

    Apply `style` to each node using the lookup.

    **dagre layout** (left-to-right `LR` direction):
    ```typescript
    const g = new dagre.graphlib.Graph();
    g.setDefaultEdgeLabel(() => ({}));
    g.setGraph({ rankdir: 'LR', nodesep: 40, ranksep: 80 });
    const NODE_WIDTH = 160;
    const NODE_HEIGHT = 60;
    nodes.forEach((n) => g.setNode(n.id, { width: NODE_WIDTH, height: NODE_HEIGHT }));
    edges.forEach((e) => g.setEdge(e.source, e.target));
    dagre.layout(g);
    nodes.forEach((n) => {
      const pos = g.node(n.id);
      n.position = { x: pos.x - NODE_WIDTH / 2, y: pos.y - NODE_HEIGHT / 2 };
    });
    ```

    **Edges:**
    Linear chain: `api-request → validation → dedup → usage-period → products → compute-run → metric-results → intelligence-update`

    If `priorPeriod` exists, add a dashed edge from `'usage-period'` to `'prior-period'`:

    ```typescript
      label: 'supersedes',
      markerEnd: { type: MarkerType.ArrowClosed }
    }
    ```

    Standard edges: solid line, `markerEnd: { type: MarkerType.ArrowClosed }`.

    **Create `components/admin/data-map/TraceGraph.tsx`:**

    Props: `{ selectedId: string }`

    Fetch trace: `const { data, isLoading } = useSWR<TraceResponse>('/api/admin/data-map/periods/' + selectedId + '/trace');`

    State:
    - `const [nodes, setNodes, onNodesChange] = useNodesState([]);`
    - `const [edges, setEdges, onEdgesChange] = useEdgesState([]);`
    - `const [drawerNode, setDrawerNode] = useState<Node | null>(null);`

    Build graph when data loads:
    ```typescript
    useEffect(() => {
      if (!data) return;
      const { nodes: n, edges: e } = buildTraceGraph(data);
      setNodes(n);
      setEdges(e);
    }, [data]);
    ```

    Loading state: Show AntD `Spin` centered while `isLoading`.

    Render:
    ```tsx
    <div style={{ width: '100%', height: '100%' }}>
      <ReactFlow
        nodes={nodes}
        edges={edges}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onNodeClick={(_, node) => setDrawerNode(node)}
        fitView
        fitViewOptions={{ padding: 0.2 }}

        <Background />
        <Controls />
        <MiniMap />
      </ReactFlow>
      <NodeDrawer node={drawerNode} onClose={() => setDrawerNode(null)} />
    ```
