  <name>Task 1: Build FeedPanel component</name>
  <files>components/admin/data-map/FeedPanel.tsx</files>
  <action>
    Create `components/admin/data-map/FeedPanel.tsx`.

    **Props:** `{ selectedId: string | null; onSelect: (id: string) => void }`

    **State:**
    - `page` (number, default 1)
    - `search` (string, default '')
    - `searchInput` (string, default '') — debounced; update `search` on 300ms debounce using `useEffect`
    - `statusFilter` (string | undefined)
    - `computeStatusFilter` (string | undefined)
    - `dateFrom` (string | undefined)
    - `dateTo` (string | undefined)

    **Data fetching:** Use `useSWR` with key built from all filter/search/page state:
    ```typescript
    const params = new URLSearchParams({ page: String(page), pageSize: '20' });
    if (search) params.set('search', search);
    if (statusFilter) params.set('status', statusFilter);
    if (computeStatusFilter) params.set('computeStatus', computeStatusFilter);
    if (dateFrom) params.set('dateFrom', dateFrom);
    if (dateTo) params.set('dateTo', dateTo);
    const { data, isLoading } = useSWR<PeriodsResponse>(`/api/admin/data-map/periods?${params}`);
    ```

    **Auto-select first row:** Use `useEffect` watching `data`:
    ```typescript
    useEffect(() => {
      if (data?.periods?.length && !selectedId) {
        onSelect(data.periods[0].id);
      }
    }, [data]);
    ```

    **Layout:** Vertical flex column — filter row on top, table below.

    **Filter row:** Use AntD `Space` and `Input.Search` for the search bar. Add AntD `Select` dropdowns:
    - Status: options `[{ value: '', label: 'All Statuses' }, { value: 'active', label: 'Active' }, { value: 'superseded', label: 'Superseded' }, { value: 'failed', label: 'Failed' }, { value: 'needs_review', label: 'Needs Review' }]`
    - Compute Status: options `[{ value: '', label: 'Any Compute' }, { value: 'success', label: 'Compute OK' }, { value: 'failed', label: 'Compute Failed' }]`

    Do NOT add date range pickers in this plan — keep the filter row simple (search + 2 selects). Date range is a stretch that can be added later.

    **AntD Table columns:**
    ```
    1. Date Range — render dateMin–dateMax as "MMM D, YYYY – MMM D, YYYY" using dayjs. If null, show "—".
    2. RSP Org — render period.org.name
    3. Status — AntD Tag with color: active=green, superseded=orange, failed=red, needs_review=blue
    4. Impact — render co2AvoidedKg as "X kg CO₂" or "—" if null
    5. Ingested — render createdAt as relative time ("2 hours ago") using dayjs().fromNow()
    6. Products — render productCount as plain number
    ```

    **Row selection:** Use `rowClassName` to highlight selected row:
    ```typescript
    rowClassName={(record) => record.id === selectedId ? 'ant-table-row-selected' : ''}
    ```
    And `onRow`:
    ```typescript
    onRow={(record) => ({ onClick: () => onSelect(record.id) })}
    ```

    **Pagination:** Use AntD Table's `pagination` prop:
    ```typescript
    pagination={{ current: page, pageSize: 20, total: data?.total ?? 0, onChange: (p) => setPage(p), showSizeChanger: false }}
    ```

    **Loading:** Pass `loading={isLoading}` to Table.

    Import dayjs. Import `useSWR` from 'swr'. Import AntD components: `Table`, `Input`, `Select`, `Space`, `Tag`.
