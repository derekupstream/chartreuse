<task type="auto">
  <name>Task 1: Build paginated periods feed API</name>
  <files>pages/api/admin/data-map/periods.ts</files>
  <action>
    Create `pages/api/admin/data-map/periods.ts` as a GET-only Next.js API route.

    **Auth:** UPSTREAM_ADMIN check using `createSupabaseApiClient` pattern (see interfaces above).

    **Query params accepted:**
    - `page` (number, default 1)
    - `pageSize` (number, default 20, max 100)
    - `search` (string) — filter by org name ILIKE, clientExternalId ILIKE, or submittedByKeyId (UUID match)
    - `rspOrgId` (UUID string) — filter by orgId exact match
    - `status` (string) — filter by status exact match: 'active' | 'superseded' | 'failed' | 'needs_review'
    - `dateFrom` (ISO string) — filter where dateMin >= dateFrom
    - `dateTo` (ISO string) — filter where dateMax <= dateTo
    - `computeStatus` (string) — 'success' | 'failed' | 'running' — filter by related ComputeRun status

    **Prisma query:**
    ```
    prisma.usageTimePeriod.findMany({
      where: { ...filters },
      include: {
        org: { select: { id: true, name: true } },
        submittedByKey: { select: { id: true, keyPrefix: true } },
        products: { select: { id: true } }, // just count
        computeRuns: {
          select: { id: true, status: true, runType: true },
          orderBy: { createdAt: 'desc' },
          take: 1
        }
      },
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * pageSize,
      take: pageSize
    })
    ```

    Also run `prisma.usageTimePeriod.count({ where: ...same filters })` for total count.

    **Search:** When `search` param is present, build OR clause:
    ```
    OR: [
      { org: { name: { contains: search, mode: 'insensitive' } } },
      { clientExternalId: { contains: search, mode: 'insensitive' } },
    ]
    ```
    If search looks like a UUID (test with simple regex `/^[0-9a-f-]{36}$/i`), also include `{ id: search }` and `{ submittedByKeyId: search }`.

    **computeStatus filter:** If `computeStatus` provided, add: `{ computeRuns: { some: { status: computeStatus, runType: 'rsp_usage' } } }`

    **Response shape:**
    ```typescript
    {
      periods: Array<{
        id: string;
        createdAt: string;
        status: string;
        dateMin: string | null;
        dateMax: string | null;
        clientExternalId: string | null;
        co2AvoidedKg: number | null;
        waterSavedGallons: number | null;
        wasteDivertedLbs: number | null;
        supersededById: string | null;
        productCount: number;
        org: { id: string; name: string };
        submittedByKey: { id: string; keyPrefix: string } | null;
        latestComputeRun: { id: string; status: string; runType: string } | null;
      }>;
      total: number;
      page: number;
      pageSize: number;
    }
    ```

    Map `products` array to `productCount: products.length` and `computeRuns[0]` to `latestComputeRun`.

    Only allow GET method. Return 405 for other methods.
  </action>

  <action>
    Create `pages/api/admin/data-map/periods/[id]/trace.ts` as a GET-only API route.

    **Auth:** Same UPSTREAM_ADMIN check pattern.

    **Prisma query:**
    ```
    prisma.usageTimePeriod.findUnique({
      where: { id: req.query.id as string },
      include: {
        org: { select: { id: true, name: true } },
        submittedByKey: { select: { id: true, keyPrefix: true } },
        products: true,  // full product rows for drawer details
        computeRuns: {
          where: { runType: 'rsp_usage' },
          include: { metricResults: true },
          orderBy: { createdAt: 'desc' },
          take: 1
        }
      }
    })
    ```

    If not found, return 404 `{ error: 'Period not found' }`.

    **Also fetch the superseded prior period** (if any) for the supersession edge:

    ```
    // If period.supersededById exists:

    })
    ```
