**In components/admin/data-map/TraceGraph.tsx:**

Add `useRouter` import from 'next/router' and a `Badge` import from 'antd'.

Create a custom node type that renders the issue badge. React Flow supports custom node types via the `nodeTypes` prop. However, since we have only simple default nodes, the simpler approach is to render the badge as an overlay using React Flow's `onNodesChange` — but this is complex.

A simpler approach: use React Flow's `nodeTypes` to register a single custom node type called `'default'` that wraps the default rendering with an optional badge overlay. Since all nodes already use the default type, this intercepts all nodes.

Actually, the cleanest approach matching the existing pattern (avoiding React Flow custom node type complexity): add an `IssueBadge` component that renders as a floating element in the React Flow canvas. But React Flow doesn't support arbitrary overlays easily.

**Use this approach instead:** Add a `nodeTypes` map with a single custom node component `IssueNode` that renders the label + optional badge:

```typescript
import { Badge } from 'antd';
import { useRouter } from 'next/router';
import type { NodeProps } from 'reactflow';
import ReactFlow, { Background, Controls, MiniMap, useEdgesState, useNodesState } from 'reactflow';

function IssueNode({ data }: NodeProps) {
  const router = useRouter();
  const issueCount: number = data.issueCount ?? 0;
  const hasIssues = issueCount > 0;

  function handleBadgeClick(e: React.MouseEvent) {
    e.stopPropagation(); // Don't open NodeDrawer
    const entityId: string | undefined = data.period?.id;
    if (entityId) {
      router.push(`/admin/data-science/inputs?entityId=${entityId}`);
    }
  }

  return (
    <div style={{ padding: '8px 12px', fontSize: 12, textAlign: 'center' }}>
      {hasIssues ? (
        <Badge
          count={issueCount}
          style={{ cursor: 'pointer' }}
          onClick={handleBadgeClick}
        >
          <span>{data.label}</span>
        </Badge>
      ) : (
        <span>{data.label}</span>
      )}
    </div>
  );
}

const nodeTypes = { default: IssueNode };
```

Pass `nodeTypes` to the ReactFlow component:
```tsx
<ReactFlow
  nodes={nodes}
  edges={edges}
  nodeTypes={nodeTypes}
  onNodesChange={onNodesChange}
  onEdgesChange={onEdgesChange}
  onNodeClick={(_, node) => setDrawerNode(node)}
  fitView
  fitViewOptions={{ padding: 0.2 }}
>
```

Update graphLayout.ts to add `entityId: trace.period.id` to both the usage-period and products node data, and update IssueNode to use `data.entityId` instead of `data.period?.id`.
