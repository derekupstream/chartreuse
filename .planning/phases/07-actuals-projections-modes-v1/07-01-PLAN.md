  <name>Task 1: Create actuals-trace and projections-trace API routes</name>
  <files>pages/api/admin/data-map/actuals-trace.ts, pages/api/admin/data-map/projections-trace.ts</files>
  <action>
Create two GET-only API routes using the `handlerWithUser().get(...)` + `checkIsUpstream` auth pattern.

**actuals-trace.ts** — `GET /api/admin/data-map/actuals-trace?projectId=`
- Require `projectId` query param (UUID). Return 400 if missing.
- Fetch:
  ```
  const project = await prisma.project.findUnique({
    where: { id: projectId },
    select: { id: true, name: true, category: true, orgId: true }
  });
  const milestones = await prisma.projectMilestone.findMany({
    where: { projectId },
    orderBy: { snapshotDate: 'asc' },
    select: { id, snapshotDate, label, source, co2AvoidedMtco2e, waterSavedGallons, wasteDivertedLbs, annualCostSavings, paybackMonths, computeRunId }
  });
  const computeRuns = await prisma.computeRun.findMany({
    where: { projectId, runType: { in: ['actuals_ingest', 'backfill'] } },
    orderBy: { startedAt: 'desc' },
    take: 10,
    select: { id, status, runType, startedAt, finishedAt, errorText, results: { select: { id, metricKey, valueNumeric, units } } }
  });
  ```
- Shape response: `{ project, milestones, computeRuns }` where each computeRun includes a `metricResults` array (rename `results` to `metricResults` in response shaping).
- Return 404 if project not found.

**projections-trace.ts** — `GET /api/admin/data-map/projections-trace?projectId=`
- Require `projectId` query param. Return 400 if missing.
- Fetch:
  ```
  const project = await prisma.project.findUnique({
    where: { id: projectId },
    select: { id: true, name: true, category: true, orgId: true }
  });
  const singleUseItems = await prisma.singleUseLineItem.findMany({
    where: { projectId },
    select: { id, productId, caseCost, casesPurchased, frequency }
  });
  const reusableItems = await prisma.reusableLineItem.findMany({
    where: { projectId },
    select: { id, productName, caseCost, casesPurchased }
  });
  const latestComputeRun = await prisma.computeRun.findFirst({
    where: { projectId, runType: 'projection' },
    orderBy: { startedAt: 'desc' },
    select: { id, status, runType, startedAt, finishedAt, errorText, results: { select: { id, metricKey, valueNumeric, units } } }
  });
  ```
- Shape response:
  ```ts
  {
    project,
    lineItemSummary: {
      singleUseCount: singleUseItems.length,
      reusableCount: reusableItems.length,
      singleUseItems,   // full list for drawer details
      reusableItems
    },
    computeRun: latestComputeRun
      ? { ...latestComputeRun, metricResults: latestComputeRun.results }
      : null
  }
  ```
- Return 404 if project not found.

Both routes: use `import prisma from 'lib/prisma'` and import `NextApiRequestWithUser` from `lib/middleware/getUser`.
